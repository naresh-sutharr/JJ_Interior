# Luxury Interior Studio Website

## Overview
Build the homepage as a polished, single-page editorial experience for a fictional high-end studio, using premium generated interior photography, generous whitespace, and restrained cinematic motion.

## What I’ll build
- Transparent overlay navigation with smooth section links, a compact mobile menu, and adaptive styling after scrolling.
- Full-screen photographic opening with the supplied headline, supporting copy, and understated work link.
- Asymmetric studio introduction and story sections using oversized editorial typography and architectural photography.
- Immersive featured-project presentation for four projects, with varied large-image compositions and project metadata.
- Typography-led services list with contextual image reveals on hover and accessible touch behavior.
- Horizontal five-step process that adapts into a refined vertical sequence on small screens.
- Asymmetric editorial gallery, a spacious testimonial, dramatic final contact section, and minimal footer.
- Functional interactions for navigation, contact actions, mobile menu, image hovers, scroll reveals, parallax, and reduced-motion preferences.
- Responsive layouts for desktop, tablet, and mobile, with stable image proportions and careful text wrapping.

## Visual system
- Warm ivory and off-white surfaces, charcoal and deep brown text, muted beige, and restrained champagne accents.
- Elegant display serif paired with a modern sans-serif body family.
- Mostly square corners, fine rules, editorial spacing, and minimal use of framed elements.
- A cohesive set of original interior and studio images generated specifically for this design; no remote placeholders.

## Technical details
- Define all color, font, spacing, and motion tokens in the global design system.
- Keep the experience at `/` and use semantic sections because the brief explicitly describes one continuous homepage.
- Add unique homepage metadata, Open Graph text, Twitter card metadata, accessible alt text, and semantic heading structure.
- Use lightweight CSS transitions plus small React observers for scroll states and reveals; no heavy animation dependency.
- Validate rendering and interactions in Chromium at desktop and mobile widths, including overlap and console checks.
